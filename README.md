# WordStep — 英単語トレーナー

Android・iPhoneのブラウザで使う、個人学習向けのPWAです。Reactなどのビルド環境は不要な静的Webアプリとして作成しています。HTML/CSS/JavaScriptを編集しながら学びやすい構成です。

## 現在実装している機能

- 500件の単語・熟語データ（`public/data/words.json`）
- 英語→日本語（選択式）
- 日本語→英語（スペル入力）
- 音声→意味（ブラウザーの英語読み上げ＋選択式）
- スペル入力
- 1セッション10問
- 正誤判定、例文の表示
- 単語×学習モードごとの回答履歴・習熟度
- 苦手単語・期限到来の単語を優先する復習
- 累計・直近の正答率、学習セッションの表示
- IndexedDBへの端末内保存（非対応時はlocalStorageへフォールバック）
- JSONバックアップ・復元、学習記録のリセット
- PWA manifest、Service Workerによるアプリ本体・単語データのキャッシュ

## 注意点

- 初版の音声は、ブラウザーの `SpeechSynthesis` を使います。音声の種類やオフライン再生可否は端末・ブラウザーに依存します。実際の音声ファイルを収録してオフライン再生する機能は未実装です。
- 500件の語彙データはアプリを動かすための初期デッキです。重複IDはありませんが、熟語・技術用語も含みます。例文や訳にはテンプレート生成されたものが含まれるため、学習用の最終版として使う前に校正・自然さの確認をおすすめします。
- データはブラウザー単位で保存されます。ブラウザーのデータ削除や端末変更で消える可能性があるため、設定画面から定期的にバックアップしてください。
- PWAのインストールとService WorkerにはHTTPSまたはlocalhostが必要です。`file://` で `index.html` を直接開かないでください。

## PCでの動作確認

1. ZIPを展開します。
2. 展開した `english-word-trainer` フォルダーでターミナルを開きます。
3. Python 3が入っている場合、次を実行します。

   ```bash
   python -m http.server 8080
   ```

   Windowsで `python` が見つからない場合は `py -m http.server 8080` を試してください。
4. 同じPCのブラウザーで `http://localhost:8080` を開きます。
5. 10問の学習、結果画面、学習記録、バックアップを確認します。
6. オフライン確認は、いったんオンラインでアプリを開いた後、開発者ツールでネットワークをOfflineにして再読み込みします。Service Workerのインストールが完了している必要があります。

## Androidで使う方法

最も簡単なのは、プロジェクトをHTTPS対応の静的ホスティング（例：GitHub PagesやNetlify）へ配置して公開URLを開く方法です。

1. `english-word-trainer` フォルダー内のファイルを、静的ホスティングへアップロードします（`index.html` が公開ルートに来るようにします）。
2. AndroidのChromeで公開URLを開き、最初の読み込みを完了させます。
3. Chromeのメニューから「アプリをインストール」または「ホーム画面に追加」を選びます（表示は端末により異なります）。
4. もう一度オンラインで起動した後、機内モードにして学習画面・履歴が動くか確認します。

PCの `http://localhost:8080` はPC自身でしか `localhost` として扱われません。PCのLAN IPを使った通常のHTTP URLでは、PWA機能が制限される場合があります。スマートフォンへの本格的な導入はHTTPS公開をおすすめします。

## 単語データの編集

`public/data/words.json` はJSON配列です。各項目には `id`, `word`, `meanings`, `exampleEn`, `exampleJa`, `pronunciation`, `audioUrl`, `level`, `category`, `tags`, `acceptedAnswers` があります。追加する場合は、`id` を一意にし、JSONとして正しい形式を保ってください。
